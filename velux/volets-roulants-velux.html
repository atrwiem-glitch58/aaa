Guide d'identification

Comment trouver le code dimensionnel de votre fenêtre Velux ?

Pour sélectionner le volet au millimètre près dans le simulateur ci-dessous, relevez la référence figurant sur la plaque d'immatriculation de votre fenêtre :

Étape 1
Ouvrir la fenêtre
Basculez l'ouvrant de votre fenêtre de toit vers l'intérieur pour laisser apparaître le haut du châssis.
Étape 2
Localiser la plaque d'identité
Sur la partie haute de la tranche (à droite ou à gauche), repérez la petite plaque métallique ou synthétique.
Étape 3
Relever le code modèle
La plaque indique un code type GGL MK06 3059. C'est le code central (MK06) qu'il faut choisir.
Fenêtres anciennes : Si votre plaque affiche d'anciens codes comme 6 ou 9 (ex: GGL 4 ou GGL 6), sélectionnez l'option Ancien Code 6 ou 9 dans le sélecteur ci-dessous.
